## Поиск запчастей

Тестовый поиск по веб-сервису «Проценка».
Поиск выполняется по артикулу. В выпадающем списке отображаются бренды.
Выбор бренда запускает поиск запчастей по артикулу и бренду, включая аналоги.

### Стек

- React 19
- Bootstrap 5
- React-Bootstrap
- Redux Toolkit
- Vite

### Запуск

```bash
npm install
cp .env.example .env
npm run dev
```

### Настройка

Ключ покупателя можно задать в `.env` (`VITE_API_KEY`) или вставить в форму.
